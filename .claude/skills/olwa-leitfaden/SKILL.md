# OLwA-Leitfaden – Wissenschaftliches Arbeiten

Kondensierte Regeln aus dem **OLwA-Leitfaden** (UZH, 7. Auflage, Backhaus & Tuor).
Vollständige Darstellung → Reference-Files unter `references/`.

## 1. GRUNDPRINZIPIEN

```
WISSENSCHAFT:
  - Alles nachvollziehbar halten
  - Meinungen und Fakten nicht vermischen
  - Neue Erkenntnisse gewinnen wollen

PLAGIAT: "Kein Kavaliersdelikt, sondern Diebstahl geistigen Eigentums!"
  → Was übernommen wird, muss sichtbar werden
  → Auch gegenseitiges Abschreiben = Plagiat

INTERSUBJEKTIVITÄT:
  → Resultate nachvollziehbar
  → Tatsachen vs. Meinungen trennen
  → Datenherkunft dokumentieren
```

→ Vertiefung: `references/aufbau-und-stil.md`

## 2. FORSCHUNGSPROZESS

```
FRAGESTELLUNG: "Ohne klar umschriebene Fragestellung → Gefahr des Ausuferns."
  → Entwicklung = Prozess (erst mit Datenanalyse abgeschlossen)
  → Im Zentrum jeder wissenschaftlichen Arbeit

HYPOTHESEN:
  → Basiert auf Stand der Forschung
  → Gibt theoretisch mögliche Antwort auf Fragestellung
  → Wahl des Ansatzes muss begründet werden

OPERATIONALISIERUNG: Zentrale Begriffe definieren, Erhebungsverfahren festlegen

INTERPRETATION: "Daten allein, ohne Analyse, sind keine Resultate!"
  → Falsifikationsversuch der Hypothese
  → Bezug zum Wissensstand herstellen
```

→ Vertiefung: `references/forschungsprozess.md`

## 3. LITERATURRECHERCHE

```
STRATEGIE: Zuerst Was und Wie der Suche definieren. Unfokussiert = ineffizient.
HIERARCHIE: Nachschlagewerke → Fachzeitschriften → Schneeballsystem
INTERNET: Kritisch hinterfragen (fehlende Redaktion)
VERWALTUNG: Format vor Durchsicht festlegen, Seitenverweise sofort notieren
```

→ Vertiefung: `references/literaturrecherche.md`

## 4. LITERATURVERARBEITUNG

```
LESEMODI: Überfliegen → Orientieren → Selektiv → Lernend
EXZERPIEREN: Relevante Info herausziehen, Strukturexzerpte anlegen
"Jeder Aneignung eines Lesestoffes müssen Denkprozesse zugrunde liegen."
```

→ Vertiefung: `references/literaturverarbeitung.md`

## 5. AUFBAU & STIL

```
STRUKTUR: Titelblatt → Inhaltsverzeichnis → Einleitung → Hauptteil → Schluss → Literatur

ROTER FADEN: "Kohärenz: Bei jedem Kapitel Zusammenhang zum Ganzen herstellen."
  → Argumentationsketten nicht zerreißen
  → Umfang ~ inhaltliche Bedeutung
  → Max 3 Dezimalstellen (z.B. "2.2.3")

KAPITEL: Einleitung (Thema, Stand, Frage, Methode) → Hauptteil → Zwischenfazit

STIL:
  → Treffend, kurz, eindeutig verständlich
  → Keine Bandwurmsätze, keine hochgestochene Sprache
  → Meinungen nüchtern formulieren
  → Gender-neutral: Eine Form wählen, konsequent durchhalten
```

→ Vertiefung: `references/aufbau-und-stil.md`

## 6. ZITIEREN

```
GRUNDREGEL: Wann immer Argumente/Daten übernommen → Quelle angeben
  → Gleiches Zitiersystem durchgängig
  → Zitate deuten, nicht um ihrer selbst willen
  → Überschuss an direkten Zitaten schadet

DIREKT: In Anführungszeichen + exakte Seite. Auslassungen: [...]. Fehler: [sic!].
INDIREKT: Sinngemäß + Quelle + Konjunktiv I.
SEKUNDÄR (vermeiden!): Nur wenn Primärquelle nicht zugänglich.
SEITEN: Genau angeben. "32ff" ist ungenau.
```

→ Vertiefung: `references/zitieren.md`

## 7. LITERATURVERZEICHNIS

```
→ Alle beigezogenen Schriften, alphabetisch
→ Alle AutorInnen aufführen (im Text ab 3: "et al.")
→ Einheitliche Darstellung
→ Internetquellen: AutorIn, Titel, URL, Zugriffsdatum. Ohne → nicht zitierfähig.
```

→ Vertiefung: `references/literaturverzeichnis.md`

## 8. SCHREIBPROZESS

```
VORBEREITUNG: "Wilde Schreibaktionen bei unklarem Konzept bringen nichts."
  → Disposition/Gliederung vor Schreiben
  → Pro Kapitel: Fokus, Stichworte, Literatur, ungefähre Seitenzahl

GEGEN BLOCKADEN:
  → Zwei-Satz-Technik: Nur letzte 2 Sätze lesen, weiterfahren
  → E-Mail-Technik: Einer Freundin erklären was man sagen will
  → Crash-Technik: Vorstellen Computer abgestürzt, frei neu formulieren

ÜBERARBEITUNG: "Genügend Zeit für das Redigieren einplanen!"
```

→ Vertiefung: `references/schreibcoaching.md`
