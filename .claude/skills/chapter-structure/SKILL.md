# Kapitelstruktur – Akademischer Aufbau

## ANATOMIE EINES KAPITELS

```
KAPITEL X: [Titel]
├── EINLEITUNG (1-2 Absätze): WAS wird behandelt? WARUM relevant? WIE aufgebaut?
├── UNTERKAPITEL X.1: Einordnung → Hauptteil → Überleitung
├── UNTERKAPITEL X.2: Einordnung → Hauptteil → Überleitung
└── ZWISCHENFAZIT (1-2 Absätze): Zusammenfassung → Rückbindung Forschungsfrage → Überleitung
```

## ABSATZ-MUSTER: These → Beleg → Interpretation → Überleitung

```
THESE (1 Satz): "Die Regulierung erfordert einen risikobasierten Ansatz."
BELEG (1-3 Sätze): "Laut Müller (2024, S. 42) sei der Ansatz darauf ausgelegt..."
INTERPRETATION (1-2 Sätze): "Für den Unternehmenskontext bedeutet dies..."
ÜBERLEITUNG (1 Satz): "Welche Risikoklassen definiert werden, zeigt der nächste Abschnitt."
```

## ÜBERLEITUNGEN

```
✅ KAUSAL: "Aufbauend auf den Grundlagen wird nun die Umsetzung betrachtet."
✅ KONTRASTIV: "Während 2.1 die Theorie darlegte, widmet sich 2.2 der Praxis."
✅ VERTIEFEND: "Nach den allgemeinen Anforderungen folgt die detaillierte Analyse."
❌ ABRUPT: Kapitel endet. Neues beginnt ohne Bezug.
❌ FLOSKELHAFT: "Im Folgenden wird nun..." (ohne inhaltlichen Bezug)
❌ REDUNDANT: "Wie bereits erwähnt..." (→ Strukturproblem)
```

## KOHÄRENZ-CHECK (PFLICHT pro Abschnitt)

```
CHECK(section, roter_faden):
  1. ANKNÜPFUNG: Referenziert Einleitung das vorherige Kapitel? Klar warum JETZT?
  2. TERMINOLOGIE: Schlüsselbegriffe konsistent zu früheren Kapiteln?
  3. RÜCKBEZÜGE: Cross-Referenzen korrekt? Keine redundante Wiederholung?
  4. FORSCHUNGSFRAGE: Beitrag AN DIESEM PUNKT klar? Progressiver Aufbau?
  5. FLUGHÖHE: Detailtiefe passt zum bisherigen Niveau? Keine großen Sprünge?
```

## HÄUFIGE PROBLEME

| Problem | Lösung |
|---------|--------|
| Fehlender roter Faden | Übergänge + Zwischenfazits ergänzen |
| Zu viel Beschreibung, wenig Analyse | These-Beleg-Interpretation anwenden |
| Aufgeblähte Kapitel (>15 Seiten) | In Unterkapitel aufteilen (max 5-8 S.) |
| Verwaiste Unterkapitel (X.1 ohne X.2) | X.2 ergänzen oder X.1 integrieren |
| Exkurse | In Fußnote oder streichen |
| Ergebnisse in Theorie | Strikt trennen |
