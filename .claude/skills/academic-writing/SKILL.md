# Wissenschaftliches Schreiben – Standards

## KERNPRINZIP: Intersubjektivität
```
CHECK:
  ├── Fachfremder Leser kann Argumentation nachvollziehen?
  ├── Jeder Gedankensprung explizit?
  ├── Fachbegriffe bei Erstverwendung definiert?
  ├── Quelle für jede nicht-triviale Aussage?
  └── Anderer Forscher käme zum gleichen Ergebnis?
```

## GEBOTE

| Regel | Beispiel |
|-------|---------|
| Präzision | ✅ "Die Studie zeigt einen Zusammenhang" ❌ "Es gibt gewisse Zusammenhänge" |
| Objektivität | ✅ "Laut Müller (2024)..." ❌ "Ich finde, dass..." |
| Konjunktiv I (indirekte Rede) | ✅ "Müller betont, die Methode sei reliabel" |
| Aktiv wo möglich | ✅ "Die Studie untersucht..." ❌ "Es wird untersucht..." |
| Hedging bei Unsicherheit | ✅ "deuten darauf hin" ❌ "beweisen" |
| Terminologie konsistent | Nicht zwischen "KI", "Künstliche Intelligenz", "AI" wechseln |
| Gender-neutral | ✅ "Mitarbeitende" durchgängig |

## VERSTÄNDLICHKEIT (Lesefluss)

Wissenschaftlich heißt **nicht** kompliziert. Die Präzision bleibt, der Satzbau wird leicht lesbar.

| Regel | Statt | Besser |
|-------|-------|--------|
| Ein Gedanke pro Satz | ein Satz mit 3+ Nebensätzen | in zwei Sätze teilen |
| These zuerst, Beleg danach | verschachtelter Vorlauf | Kernaussage voran |
| Einschübe sparsam | mehrere „–"/Klammer-Einschübe pro Satz | max. 1, sonst eigener Satz |
| Verb statt Nominalstil | „nimmt eine Verschiebung vor" | „verschiebt sich" |
| Kernthesen direkt benennen | abgeschwächt, verschachtelt | klar und kurz |

FAUSTREGEL: Sätze meist < 25 Wörter. Ab dem zweiten Komma prüfen, ob zwei Sätze klarer sind. Fachbegriffe bleiben (Präzision!) – vereinfacht wird der Satzbau, nicht der Inhalt.

## VERBOTEN

```
❌ KI-FLOSKELN: "Es ist wichtig zu beachten", "In der heutigen Zeit",
   "Es lässt sich festhalten", "Wie bereits erwähnt",
   "Zusammenfassend lässt sich sagen", "Im Folgenden wird erläutert"
❌ MARKETING: "revolutionär", "bahnbrechend", "state-of-the-art" (ohne Quelle)
❌ UNBELEGT: "Studien zeigen" (WELCHE?), "Experten sind sich einig" (WELCHE?)
❌ AUFGEBLÄHT: 3 Sätze wo 1 reicht, redundante Synonyme, Nominalstil-Ketten
❌ PLAGIAT: Copy-Paste ohne Zitat, Umformulierung einer Quelle über Absätze
```

## ZITIERREGELN

```
DIREKT: Wörtlich in Anführungszeichen + exakte Seitenangabe.
  "Die KI-Verordnung stellt einen Paradigmenwechsel dar" @mueller2024[S. 42].
  Bei >3 Zeilen: Eingerückt, ohne Anführungszeichen.

INDIREKT: Sinngemäß + Quelle + Konjunktiv I.
  Laut Schmidt (2023) sei die Regulierung eine zentrale Herausforderung (vgl. S. 15).

SEKUNDÄR (vermeiden!): Nur wenn Primärquelle nicht zugänglich.
  Weber (2020, zitiert nach Müller, 2024, S. 42). ⚠️ Warnsignal für schlechte Quellenarbeit!
```

## ABSATZ-CHECK

| Frage | FAIL | PASS |
|-------|------|------|
| Nicht-triviale Aussage belegt? | "Ist allgemein bekannt" | Quelle + Seite |
| Klingt nach KI? | "Es ist wichtig..." | Direkt, präzise |
| Konjunktiv korrekt? | "die Methode ist" | "die Methode sei" |
| Terminologie konsistent? | Synonyme wechseln | Ein Begriff = eine Bedeutung |
| Absatz zu lang? | >8 Zeilen unstrukturiert | 3-6 Sätze, klarer Gedanke |
| Satz zu verschachtelt? | >25 Wörter, 3 Nebensätze | 1 Gedanke, ggf. zwei Sätze |
| Roter Faden? | Abrupter Themenwechsel | Explizite Überleitung |
